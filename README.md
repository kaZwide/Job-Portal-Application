# Job Portal Application

A full-stack Job Portal application developed as part of the Auspify programme.

## Project Description

This application allows users to create an account, log in, search for available jobs and submit job applications. It also includes an administrator dashboard for managing job listings and reviewing submitted applications.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- better-sqlite3
- bcryptjs
- express-session

## Features

- User registration and login
- Secure password hashing
- Job search and location filtering
- Job listings
- Job posting
- Job application submission
- Application status management
- Administrator dashboard
- Administrator access control
- SQLite database storage

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install the required dependencies:

   npm.cmd install

4. Start the server:

   node server.js

5. Open the application in your browser:

   http://localhost:3000

## Administrator Dashboard

The administrator dashboard is protected and can only be accessed by a logged-in user with the administrator role.

## Database

SQLite is used to store user accounts, job listings and submitted job applications.
